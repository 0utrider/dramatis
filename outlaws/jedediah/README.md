# Jedediah "Doc" Hale, The Doc

| Field | Value |
| --- | --- |
| Campaign | Outlaws of Alkenstar (PF2e) |
| GM | Wrangler |
| Ancestry / Class | Human / Necromancer (Spirit) |
| Background | Frontier doctor and bounty hunter |

## Description

A frontier doctor and bounty hunter who brings his marks in dead, then raises them to work off their sentences. Doc keeps a steady bedside manner with the living and the dead alike. His posse of thralls does the rest. Doc winks once per token loop, held about a second.

## Posse

Six thralls, each with keyart, portrait, token and loop under `summons/`.

| Subject | Name | What they were | Role |
| --- | --- | --- | --- |
| `thrall-01-silas` | "Sweet-Talk" Silas Vane | Snake-oil swindler | Thrall |
| `thrall-02-tilly` | "Two-Gun" Tilly Marsh | Train robber | Thrall |
| `thrall-03-durgin` | Durgin "Brickbeard" Halfhand | Dwarf claim jumper | Thrall |
| `thrall-04-grubb` | Grubb the Grease | Goblin explosives "artist" | Thrall, Doc's usual necrotic bomb |
| `thrall-05-marigold` | Marigold "Mags" Pennywhistle | Halfling horse thief | Thrall |
| `songbird-delphine` | Miss Delphine "Del" LaRue | Saloon songbird | Thrall, Song of the Soul |

## Assets

Metadata for every file is in `character.yaml`.

- `jedediah-keyart.webp`: master art (2752x1536)
- `jedediah-portrait.webp`: 1:1 portrait
- `jedediah-token`: animated token as `.webm` (use in Foundry), a lossless still `.webp` and `.png`, and `.gif` (under 8 MB, for Discord). Braid and spirit-flame ring with a silver lawman's star
- `jedediah-loop.mp4`: full 1280x720 scene, same loop as the token
- `summons/`: the six thralls above, each with `<id>-keyart.webp`, `-portrait.webp`, `-token.webm`/`.webp`/`.png` (spirit-chain ring) and `-loop.mp4`

Foundry shows a `.webp` token as a still, so use the `.webm`. The art fills one grid square and the ring overhangs it, so set the token Scale: **Doc 1.15, thralls 1.1**. The webm canvas is 588x588 for Doc and 564x564 for the thralls.
