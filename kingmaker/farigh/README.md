## Description

A tiny sentient black hole with a cracked grin, formerly known as Sparky. Farigh is Arabic for "void", and he wears it lightly: a small, bright-eyed disk of light bending around a dark sphere that never quite stops smiling.

## Assets

Metadata for every file is in `character.yaml`.

- `farigh-keyart.webp`: master art
- `farigh-portrait.webp`: 1:1 portrait
- `farigh-token`: animated token (soft gold accretion ring) as `.webm` (use in Foundry, it shows animated WebP as a still frame), `.webp`, and `.gif` (under 8 MB, for Discord); `farigh-token.png` is the static version
