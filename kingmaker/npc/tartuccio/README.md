A gnome villain in plum velvet, loyal to Irovetti of Pitax.

## Assets

Metadata for every file is in `character.yaml`.

- `tartuccio-keyart.webp`: master art
- `tartuccio-portrait.webp`: 1:1 portrait
- `tartuccio-token`: animated token (a gilded band with amethysts, a Pitax-style crest and tumbling coins) as `.webm` (use in Foundry, it shows animated WebP as a still frame) and `.webp`; `tartuccio-token.png` is the static version
- `tartuccio-loop.mp4`: 1280x720 seamless loop of the full scene (plays inline in Discord)
