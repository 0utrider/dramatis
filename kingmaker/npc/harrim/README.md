## Description

A dour dwarf in rusted power armor, with a beanie and a shotgun.

## Assets

Metadata for every file is in `character.yaml`.

- `harrim-keyart.webp`: master art
- `harrim-portrait.webp`: 1:1 portrait
- `harrim-token`: animated token (rain-rusted iron with heavy rivets and a chain at the bottom) as `.webm` (use in Foundry, it shows animated WebP as a still frame) and `.webp`; `harrim-token.png` is the static version
- `harrim-rainbow-token`: spinoff token, a rainbow unicorn skin of the same ring, as `.webm`, `.webp` and `.png`; `harrim-rainbow-token-shades.png` is the static version with shades
- `harrim-loop.mp4`: 1280x720 seamless loop of the full scene (plays inline in Discord)
