## Description

A barbarian wielding a greatsword made from a salvaged hull plate (stenciled `NCC-412`).

## Assets

Metadata for every file is in `character.yaml`.

- `amiri-keyart.webp`: master art
- `amiri-portrait.webp`: 1:1 portrait
- `amiri-token`: animated token (torn hull plate: scorched riveted steel, claw gouges, a teeth-and-feather cord, lightning and sparks) as `.webm` (use in Foundry, it shows animated WebP as a still frame) and `.webp`; `amiri-token.png` is the static version
- `amiri-loop.mp4`: 1280x720 seamless loop of the full scene (plays inline in Discord)
