## Description

Blond hair, amber eyes, silver circuit lines across his face and a sword on his back.

## Assets

Metadata for every file is in `character.yaml`.

- `deadeye-keyart.webp`: master art
- `deadeye-portrait.webp`: 1:1 portrait
- `deadeye-token`: animated token (digital scope reticle ring) as `.webm` (use in Foundry, it shows animated WebP as a still frame), `.webp`, and `.gif` (under 8 MB, for Discord); `deadeye-token.png` is the static version
